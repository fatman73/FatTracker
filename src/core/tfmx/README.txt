TFMX decoder adapted from libtfmxaudiodecoder by Michael Schwendt
(https://github.com/RetrovertApp/playback-tfmx, src/Chris), GNU GPL v2 or later.
Changes for FatTracker: the SMPL data is handed over from memory (setSamples),
debug dumps removed, PaulaVoice implemented by FatTracker (core/tfmx_player.cpp).
Because of this code, FatTracker binaries that contain TFMX support are covered by the GPL.
